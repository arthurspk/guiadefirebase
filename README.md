## :dart: O guia para alavancar a sua carreira

> Firebase é a plataforma de desenvolvimento de apps do Google: banco de dados em tempo real (Firestore e Realtime Database), autenticação pronta, hospedagem, funções serverless (Cloud Functions), notificações push, testes e, desde 2024/2025, um pacote completo de IA generativa com Genkit e Firebase AI Logic (antigo Vertex AI in Firebase). É a escolha mais comum para tirar um MVP do papel rápido — web, Android, iOS ou Flutter — sem montar um back-end do zero, e aparece com frequência em vagas de desenvolvimento mobile e full-stack no Brasil. Este guia reúne documentação oficial, cursos gratuitos e pagos (em português e em inglês), livros, canais, ferramentas, projetos práticos, comunidades e um capítulo dedicado a usar IA (Gemini, Genkit, Firebase Studio) na prática com Firebase — tudo verificado e organizado para quem quer sair do zero e chegar a um app em produção.

## 🤖 IA na prática

O Firebase é hoje também a porta de entrada oficial do Google para colocar IA generativa dentro de apps mobile e web. Em 2024/2025 a plataforma ganhou o **Genkit** (framework open source para construir funcionalidades de IA) e o **Firebase AI Logic** (antigo "Vertex AI in Firebase"), além do **Firebase Studio**, um ambiente de desenvolvimento em nuvem com assistência de IA.

**Para aprender**
- Peça para um assistente de IA **explicar uma regra de segurança do Firestore** colando a regra e um exemplo de documento, e peça para ele apontar brechas (ex.: um campo que qualquer usuário autenticado poderia sobrescrever).
- Cole o erro completo de uma `Cloud Function` que falhou no deploy e peça para o assistente explicar a causa mais provável e como reproduzir o problema localmente com a suíte de emuladores.
- Peça **exercícios com gabarito** sobre o produto que está estudando (ex.: "monte um modelo de dados de um app de tarefas no Firestore e me pergunte sobre como estruturar as coleções").
- Use o [Google AI Studio](https://aistudio.google.com/) para testar prompts com os modelos Gemini de graça, direto no navegador, antes de integrar via Genkit ou Firebase AI Logic em um app.

**Para trabalhar**
- [Genkit](https://genkit.dev/) — framework open source mantido pelo Firebase para construir aplicações com IA generativa em JavaScript, Go e Python, com um único SDK para vários modelos (Gemini, OpenAI, Claude, Ollama).
- [Firebase AI Logic](https://firebase.google.com/docs/ai-logic) — biblioteca oficial para acessar os modelos Gemini com segurança direto de apps mobile e web, sem expor a chave de API no cliente.
- [Firebase Studio](https://firebase.google.com/docs/studio) — IDE em nuvem do Google com assistência de IA para prototipar, testar e publicar apps full-stack integrados ao Firebase.
- [Gemini in Firebase](https://firebase.google.com/docs/gemini-in-firebase) — assistente de IA integrado ao console e à CLI do Firebase, que ajuda a escrever regras de segurança, código de Cloud Functions e a depurar erros.
- Use assistentes de código para gerar **regras de segurança do Firestore/Storage** — mas sempre teste no simulador de regras antes de publicar em produção.

**Limites e boas práticas**
- IA **inventa nomes de métodos e comportamento de SDKs** que não existem ou já mudaram entre versões (o SDK modular do JavaScript é um exemplo clássico de confusão com a API antiga). Confirme sempre na [documentação oficial](https://firebase.google.com/docs).
- Nunca cole **chaves de serviço (service account), tokens de usuários reais ou dados de produção** em ferramentas de IA sem a política de segurança da sua empresa.
- Toda regra de segurança sugerida por IA deve ser testada no [simulador de regras](https://firebase.google.com/docs/rules/simulator) antes de ir para produção — uma regra mal configurada pode expor os dados de todos os usuários do app.
- O plano gratuito (Spark) tem limites de uso; peça para a IA revisar o código gerado em busca de leituras/escritas desnecessárias no Firestore, que são a causa mais comum de custo inesperado no plano pago (Blaze).
